# 更新日志 Changelog

本项目的所有重要变更记录于此。版本格式遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## [1.13.0] - 2026-08-10

### 变更

- “复制全部”按钮的输出改为每个区域一行：【名称 （坐标）（备注）】，各区域信息列在一起

## [1.12.0] - 2026-08-09

### 新增

- 正式命名为“在这里 Here it is”
- 窗口标题显示产品名与版本号

### 其他

- 准备 GitHub 发布：补齐 README、CHANGELOG、许可证等发布文档
- 添加作者署名 8!!
- 附带 pick-image-coords Codex 技能包（内置 v1.9.0–v1.12.0 工具）

## [1.11.0] - 2026-08-09

### 新增

- 右侧面板顶部“复制全部（坐标+备注）”按钮，一键把全部坐标和备注复制到剪贴板

### 修复

- 矩形与圆形共用编号计数器导致“圆形2”等编号错乱的问题

## [1.10.0] - 2026-08-09

### 新增

- 圆形模式（按 `c`）：从圆心拖到边缘画圆，输出圆心坐标和半径

## [1.9.0] - 2026-08-09

### 变更

- 坐标轴方向固定：x 向右增大、y 向上增大；5 个定位按钮只决定零点位置

## [1.8.0] - 2026-08-09

### 变更

- “全局坐标定位方式”修正为整张原图坐标轴零点，所有元素坐标随零点切换自动换算
- 移除矩形定位点

## [1.7.0] - 2026-08-09

### 变更

- 形状列表只显示名称；定位方式改为全局，切换时所有已有矩形自动重算定位点

## [1.6.0] - 2026-08-09

### 新增

- 未选中点改为蓝点黄边
- 窗口拉大时图片居中
- 滚轮以指针为中心缩放、中键拖动平移

## [1.5.0] - 2026-08-09

### 新增

- 5 个坐标定位方式按钮（左上/右上/左下/右下/中心）

## [1.4.0] - 2026-08-09

### 新增

- 列表选中形状时，图片上对应的点/矩形高亮为紫色

## [1.3.0] - 2026-08-09

### 新增

- “删除选中”按钮与 Delete 键，可删除列表中任意选中的形状

## [1.2.0] - 2026-08-09

### 变更

- 放大镜升级为 400x400，显示光标周围 ±100px

## [1.1.0] - 2026-08-09

### 新增

- 矩形拉框
- 形状列表与区域说明
- 100x100 放大镜（显示光标周围 ±20px，中心十字线）

## [1.0.0] - 2026-08-09

### 新增

- 初始发布：点击图片取坐标
