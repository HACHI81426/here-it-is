选点/拉框工具 v1.11.0 使用说明
================================

【这是什么】
打开一张截图，用鼠标点几下或拉几个框，就能拿到原图坐标，
还能给每个区域写一句说明，常用于给自动化脚本标记按钮位置。

【环境准备】
1. 安装 Python 3.9 或更高版本（Windows 官方安装包默认自带 Tk，无需额外操作）
2. 在命令行执行：pip install -r requirements.txt
   （依赖只有 Pillow 一个）

【启动】
方式一：双击 start.bat，把图片文件拖到黑色窗口上，松开即可。
方式二：命令行执行 python pick_coords.py 图片路径

【取点 / 拉框操作】
- 左键点击：取一个点，图上画蓝点（黄色描边）并标注坐标（取点模式）
- 滚轮：以鼠标位置为中心放大/缩小画面；按住中键拖动可平移画面
- 窗口可以拉大，图片会保持居中
- 按 r：切换为矩形模式，按住左键拖拽拉矩形，松开后画蓝框并标注坐标
- 按 c：切换为圆形模式，从圆心按住左键拖到边缘，松开后画蓝圆并标注圆心和半径
- 按 p：切回取点模式
- 点右侧面板顶部的“复制全部（坐标+备注）”按钮：当前所有坐标和备注
  会按文本格式复制到剪贴板，按钮会短暂显示“已复制 ✓”
- 右键点击：撤销上一个形状（点或矩形）
- 在右侧列表选中某个形状后，点列表上方的“删除选中”按钮（或按 Delete 键）删除该形状
- q 或 ESC：退出，控制台打印最终坐标、矩形和说明
- 窗口底部实时显示当前模式和已取的全部形状

【坐标定位方式】
右侧有 5 个按钮：左上、右上、左下、右下、中心（默认左上）。
它决定整张原图坐标轴的零点在哪里。坐标轴方向永远不变：
x 向右增大（越靠右越大），y 向上增大（越靠上越大）。
也就是数学里常用的直角坐标系方向。
例如：
- 左下：原点在图片左下角，图片内所有坐标都是正的
- 左上：原点在图片左上角，x 为正、y 为负（内容都在原点下方）
- 右上：原点在图片右上角，x、y 都为负
- 右下：原点在图片右下角，x 为负、y 为正
- 中心：原点在图片正中，向右/向上为正，向左/向下为负
所有点与矩形的坐标都按当前零点输出，图上标注、底部状态栏、
退出输出同步换算；切换零点时，所有已添加元素自动重新换算。

【形状列表与区域说明】
右侧列表会显示所有已取的点与矩形（如“点1”、“矩形1”）。
列表只显示名称，坐标看图上标注和退出输出。
用鼠标选中某个形状，
图片上对应的点或矩形会变成紫色高亮（点变大、边框加粗），
在下方“该区域说明”文本框里输入这块区域是什么（如“登录按钮”），
退出时说明会随坐标一起输出。
注意：在文本框输入时，快捷键（r/c/p/q/ESC）不响应，
点击图片或列表后恢复。

退出时输出示例：
坐标零点: 左下
最终坐标: [(532, 482)]
最终矩形: [(120, 390, 360, 512)]
最终圆形: [(240, 300, 60)]
形状说明: {'矩形1': '登录按钮区域'}

【放大镜】
图片窗口右侧有一个 400x400 的放大镜窗口，移动鼠标时
实时显示光标周围 ±100px 的放大画面，中心有十字线，
方便对准像素精确定位。

【坐标说明】
窗口里的图片会按屏幕大小等比缩放，但输出的坐标始终是原图坐标，
只是会按右侧选定的坐标零点换算；x 向右增大、y 向上增大。
缩放不会影响数值，可以直接用于脚本。
滚轮缩放和平移也只改变显示，取到的坐标仍是原图坐标。

【常见问题】
Q: 启动报错提示缺 Tk？
A: 请使用 Python 官方安装包重新安装，安装时保持 Tcl/Tk 勾选。

Q: 双击 start.bat 一闪而过？
A: 先确认已 pip install -r requirements.txt；窗口关闭时按任意键，
   报错信息会留在窗口里。

Q: 拉框时没反应？
A: 先按 r 确认左下角状态栏显示“模式：矩形”，然后按住左键拖动，
   不能只是点击。
