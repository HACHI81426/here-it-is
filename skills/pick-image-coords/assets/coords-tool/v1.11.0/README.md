# 选点/拉框工具 v1.11.0

## 版本说明

- 版本号：v1.11.0
- 类型：Windows 桌面小工具（Python 源码，无需安装）
- 发布日期：2026-08-09
- 开源协议：MIT

## 功能

- 打开一张图片，鼠标左键点击即可取点，输出的是**原图坐标**（按所选坐标零点换算；窗口缩放不影响数值）
- 按 `r` 进入矩形模式，左键拖拽即可拉矩形，松开后输出矩形坐标（支持任意方向拖拽，坐标自动归一化）
- 按 `c` 进入圆形模式，左键从圆心按住拖到边缘，松开后输出圆心坐标和半径
- 按 `p` 回到取点模式
- 右侧面板顶部有“**复制全部（坐标+备注）**”按钮，一键把当前所有选区坐标和备注以文本格式复制到剪贴板
- 取到的点画蓝点（黄色描边）并标注坐标，矩形画蓝色边框并标注坐标
- 未选中的点显示为**蓝色带黄色描边**，在列表选中后变为紫色高亮
- 窗口可以自由拉大，图片始终**居中**显示
- 鼠标**滚轮以指针位置为中心缩放**画面（最大约 3~40 倍，视图片尺寸而定），按住鼠标**中键拖动可平移**画面
- 右侧“形状列表”只显示形状名称（如“点1”“矩形1”）与说明，不再显示坐标，界面更清爽
- 在列表选中某个形状时，图片上对应的点/矩形会高亮为紫色（点变大、边框加粗），方便对照识别
- 右侧有“全局坐标定位方式”5 个按钮（左上/右上/左下/右下/中心，默认左上），它只决定**整张原图坐标轴的零点**；坐标轴方向永远固定：**x 向右增大（越靠右越大）、y 向上增大（越靠上越大）**。所有点与矩形的坐标都按当前零点输出（可能是负值），图上标注、底部状态栏、退出输出同步换算；**切换零点时所有已添加元素自动重新换算**
- 列表上方有“删除选中”按钮，选中任意形状后点它即可删除（也可以选中后按 Delete 键），不必只能撤销最后一个
- 图片窗口右侧有 400x400 的**放大镜窗口**，实时显示光标周围 ±100px 的放大画面，中心十字线辅助精确定位
- 右键点击撤销上一个形状（点或矩形）
- 按 `q` 或 `ESC` 退出，退出时在控制台输出全部坐标与说明
- 底部状态栏实时显示当前模式与已取形状，方便复制

## 使用方法

### 环境准备

需要 Python 3.9 或更高版本（带 Tk 支持，Windows 官方安装包默认包含），并安装依赖：

```bash
pip install -r requirements.txt
```

依赖只有一个：Pillow（用于图片显示）。

### 启动

方式一：双击 `start.bat`，然后把图片文件拖到批处理窗口上松开即可打开。

方式二：命令行运行：

```bash
python pick_coords.py 图片路径.png
```

不带参数时默认打开当前目录下的 `screen.png`。

### 取点 / 拉框

1. 默认是**取点模式**，左键点击目标位置，红点出现并显示坐标
2. 按 `r` 切换到**矩形模式**，在目标区域按住左键拖拽，松开后蓝色矩形出现并显示矩形坐标
3. 按 `c` 切换到**圆形模式**，从圆心按住左键拖到边缘，松开后蓝色圆形出现并显示圆心坐标和半径
4. 按 `p` 切换回取点模式，可以继续取点、拉框或画圆
5. 点错或框错时右键撤销上一个形状
6. 想删除中间的某个形状：在右侧列表选中它，点列表上方的“删除选中”按钮（或按 Delete 键）
7. 在右侧“全局坐标定位方式”里选坐标零点（默认左上），所有点、矩形、圆形的坐标都按它输出；随时切换，已有元素自动换算
8. 在右侧列表选中某个形状，在下方文本框填写该区域的说明（如“登录按钮”），说明会随坐标一起输出
9. 移动鼠标时右侧放大镜实时放大光标周围 ±100px 的区域，中心十字线方便对准像素
10. 想随时带走数据：点右侧面板顶部的“复制全部（坐标+备注）”按钮，所有坐标和备注会按文本格式进剪贴板
11. 按 `q` 或 `ESC` 退出，控制台打印最终结果，例如：

```text
坐标零点: 左下
最终坐标: [(532, 481), (642, 379)]
最终矩形: [(120, 589, 360, 711)]
最终圆形: [(240, 400, 80)]
形状说明: {'点1': '起始点', '矩形1': '登录按钮区域'}
```

## 已知说明

- 需要系统安装带 Tk 的 Python（Windows 官方安装包默认自带，无需额外配置）
- 本工具不联网、不上传任何数据，图片只在本机内存中处理
- 在“该区域说明”文本框输入时，快捷键（r/c/p/q/ESC）暂时不响应，点击图片或列表后恢复
- 若双击 start.bat 一闪而过，先执行 `pip install -r requirements.txt`（依赖只有 Pillow）
- 滚轮缩放与平移只改变显示效果，输出的坐标始终是原图坐标，不受缩放影响
- 用于自动化脚本取坐标时，建议配合模拟器/截图工具固定窗口大小，保证坐标稳定
