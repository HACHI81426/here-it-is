选点工具技能包（pick-image-coords）安装说明
============================================

这个压缩包包含一个 Codex 技能，用来识别图片/截图里的界面元素
（按钮、输入框、图标、文字区域）并获取精确坐标。
工具本体已随技能打包在 assets/coords-tool 里，不需要另外下载。

【安装步骤】
1. 把压缩包里的 pick-image-coords 文件夹整个复制到 Codex 技能目录：
   C:\Users\<你的用户名>\.codex\skills\
   （没有这个目录就新建；放好后新开一个 Codex 对话即可识别）
2. 安装 Python 3.9 或更高版本：
   Windows 官方安装包安装时保持 Tcl/Tk 勾选（默认就是勾选的）
3. 安装依赖（只有 Pillow 一个）：
   pip install Pillow
   或者进入 assets\coords-tool 里的版本文件夹执行：
   pip install -r requirements.txt

【使用方法】
在 Codex 对话里说：
- “帮我识别这张图片里的元素”
- “给我这个按钮的坐标”
- “用 OCR 定位元素”
技能会自动启动选点工具。

也可以手动运行（在技能文件夹所在目录执行）：
python pick-image-coords\scripts\launch_pick_coords.py 图片路径 --wait

【工具操作】
- 左键点击：取一个点
- 按 r：切到矩形模式，按住左键拖拽拉框
- 按 p：切回取点模式
- 右键：撤销上一个形状
- 滚轮：以指针为中心缩放；按住中键拖动：平移画面
- q 或 ESC：退出并输出全部坐标

【坐标说明】
- 右侧“全局坐标定位方式”选择坐标零点（左上/右上/左下/右下/中心，默认左上）
- 坐标轴方向固定：x 向右增大（越靠右越大）、y 向上增大（越靠上越大）
- 输出的坐标带“坐标零点”标记，写自动化脚本时注意带上

【更新工具】
有新版本工具时，把版本文件夹复制到 assets\coords-tool\ 下即可，
启动脚本会自动使用版本号最高的那个。
