# 在这里 Here it is

一个 Windows 桌面小工具：打开图片或截图，用鼠标点选、拉框、画圆，把精确的**原图坐标**和区域备注一键复制出来，供自动化脚本、OCR 定位、UI 测试等场景使用。

> 曾用名“选点/拉框工具”，自 v1.12.0 起正式命名为 **在这里 Here it is**。

## ✨ 功能特性

- 三种取形方式：取点、拉矩形、画圆形，输出原图坐标
- 400×400 放大镜（显示光标周围 ±100px，中心十字线），像素级定位
- 全局坐标零点：左上 / 右上 / 左下 / 右下 / 中心，切换零点所有元素坐标自动换算
- 坐标轴方向固定：x 向右增大、y 向上增大（数学直角坐标系）
- 形状列表 + 区域备注，选中形状高亮显示
- 一键复制全部坐标和备注到剪贴板
- 滚轮以指针为中心缩放、中键拖动平移、窗口拉大图片居中
- 纯 Python、单文件、不联网、MIT 开源协议

## 🚀 快速开始

### 环境要求

- Windows 10/11，Python 3.9 或更高版本（安装时保持 Tcl/Tk 勾选）
- 依赖：Pillow（`pip install -r requirements.txt`）

### 运行

```bash
python pick_coords.py 图片路径.png
```

也可以双击 `start.bat`，把图片文件拖到黑色窗口上松开。

## 🖱️ 操作说明

| 操作 | 说明 |
| --- | --- |
| 左键点击 | 取一个点（取点模式，默认） |
| `r` | 切换矩形模式，按住左键拖拽拉框 |
| `c` | 切换圆形模式，从圆心按住拖到边缘画圆 |
| `p` | 切回取点模式 |
| 右键 | 撤销上一个形状 |
| 滚轮 | 以鼠标位置为中心缩放 |
| 中键拖动 | 平移画面 |
| Delete 键 / “删除选中”按钮 | 删除列表中选中的形状 |
| “复制全部（坐标+备注）”按钮 | 复制全部坐标和备注到剪贴板 |
| `q` / `ESC` | 退出并在控制台输出全部结果 |

## 📐 坐标约定

- **零点**：右侧“全局坐标定位方式”5 个按钮（左上/右上/左下/右下/中心，默认左上）决定整张原图坐标轴的零点。
- **轴方向固定**：x 向右增大（越靠右越大），y 向上增大（越靠上越大）。
- 输出坐标为原图坐标，按所选零点换算；缩放、平移不影响数值。
- 默认“左上”零点时 y 为负；选“左下”时图片内坐标全为正。

退出或复制输出示例：

```text
坐标零点: 左下
最终坐标: [(532, 481), (642, 379)]
最终矩形: [(120, 589, 360, 711)]
最终圆形: [(240, 400, 80)]
形状说明: {'点1': '起始点', '矩形1': '登录按钮', '圆形1': '头像区域'}
```
